# Pitch técnico — primera presentación

Deck técnico largo de Pronto para KermitPanic. FrontDesk es la consola
operativa del producto.

Abrir [`index.html`](index.html).

## Controles

- `←` / `→`, `Page Up` / `Page Down` o clic: navegar.
- `1`–`9` y `0`: saltar a una slide.
- `F`: pantalla completa.
- `N`: notas del presentador.

## Criterio de claims

- Arquitectura y capacidades: contrastadas con el repositorio y OpenSpec.
- `94,4%`, `82%` y `0 fugas`: objetivos del piloto, no resultados observados.
- RGPD/HIPAA: controles técnicos orientados a cumplimiento, no certificación.
- Next.js: versión 16.
- Fly.io: región `cdg` (París); `mad` no está disponible en Fly.
- Estado de producción: suite offline disponible; live gate y piloto pendientes.
